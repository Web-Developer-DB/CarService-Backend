# Sicherheitsrichtlinie

## Unterstützte Version

Nur die aktuelle `2.x`-Version wird sicherheitsrelevant gepflegt. Die frühere API wurde entfernt.

## Schwachstelle melden

Bitte keine Sicherheitslücken als öffentliches Issue veröffentlichen. Senden Sie eine reproduzierbare Beschreibung, betroffene Versionen und mögliche Auswirkungen an die im privaten Projektkanal hinterlegte Sicherheitskontaktadresse. Zugangsdaten, Tokens und personenbezogene Daten gehören nicht in den Bericht.

Wir bestätigen den Eingang, priorisieren die Meldung und koordinieren eine vertrauliche Behebung.
